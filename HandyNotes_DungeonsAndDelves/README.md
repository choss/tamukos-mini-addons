# HandyNotes: Dungeons & Delves

HandyNotes markers for dungeons and delves.

## Included maps

- Labyrinth of Kindo'jan: possible Hexmask / locked room spawns (Chamber of Rites, The Cave Towers, Akil'zon's Roost, Jan'alai's Refuge, Nalorakk's Rest)

Requires HandyNotes. Copy the `HandyNotes_DungeonsAndDelves` folder to `World of Warcraft\_retail_\Interface\AddOns\`.

## Features

- Options: icon scale/alpha, minimap toggle, tooltip notes
- Right-click a marker on the world map for a menu with Set waypoint and Add TomTom waypoint
- 'Add TomTom waypoints' button imports every spot into TomTom (if installed)
