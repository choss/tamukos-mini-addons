# HandyNotes: Labyrinth of Kindo'jan

Shows possible Hexmask / locked room spawn locations on the map in the Labyrinth of Kindo'jan.

Locations: Chamber of Rites, The Cave Towers, Akil'zon's Roost, Jan'alai's Refuge, Nalorakk's Rest.

Requires HandyNotes. Copy the `HandyNotes_Kindojan` folder to `World of Warcraft\_retail_\Interface\AddOns\`.

## Features

- Options: icon scale/alpha, minimap toggle, tooltip notes
- 'Add TomTom waypoints' button imports all five spots into TomTom (if installed)
